# 同路紫金融合版 V6 · 更新说明与验收

此版本基于上一轮「紫金智能建档版」完整项目增量修改，**沿用原仓库内 `variants/d-tonglu-purple-gold-v3/` 路径**，所以版本墙 `manifest.js` 无须再登记一个新 ID。

## 本次改进

1. 学生首页仍以 AI 对话为核心，新增「将首页对话整理为 BG」入口。**用户主动点击**后，进入可编辑字段预览；再次确认才更新正式 BG。旧版快速入口从首页移除。
2. 智能建档增加输入原文/TXT 摘录对照，帮助用户核对提取字段。PDF/Word 仍未做真正正文解析。
3. 在学生「院校资讯」「我的」中加入经验库演示入口，提供**虚构主题案例**、关键词筛选与经验摘要。未接真实历史数据库、RAG 和收费。
4. 服务者详情与服务者资料页加入认证说明，将个人申报、平台核验、真实订单统计区分开；原型中任何标记都不能代替真实认证。
5. 学生「我的」增加成长规划建议，依据已确认年级、诉求和目标生成**本地规则建议**。用户采纳后可以修改状态、个人截止日或移除，不能代替院校官方日期。
6. 新增「我的 → 资料与数据管理」，说明本机存储、导出与清除资料、未来模型/分享处理授权的占位界面。勾选不会真实上传资料，也不代表正式版有效同意。
7. 新增 `assets/integration-adapters.js` 和 `docs/API_INTEGRATION.md`：保留模型、材料解析、授权、后端数据、经验检索与服务者核验的对接契约；所有连接函数当前只返回 `not_connected`。

## 安装

1. 先备份原目录 `D:\沿途\yantu-demo\variants\d-tonglu-purple-gold-v3`。
2. 把直接替换包解压到 `D:\沿途\yantu-demo` **项目根目录**（不是 `variants` 文件夹），选择合并目录与替换同名文件。不要将补丁单独解压到 `assets` 中。
3. 在根目录运行 `py server.py`；按终端端口访问 `http://127.0.0.1:8095/variants/d-tonglu-purple-gold-v3/index.html`，按 Ctrl+F5 强制刷新。
4. 不需要更改 `manifest.js`，也不要上传备份 ZIP、测试文件或个人 BG 到 GitHub。

## 验收步骤

- 学生端首页输入「我是某大学统计专业大二，想保研和参加竞赛」→ 点击「整理为 BG」→ 修改识别字段 → 确认 → 「我的」查看成长建议 → 采纳一条 → 修改任务状态。
- 从「院校资讯」打开经验库，检索「人工智能」并展开摘要；检查演示与来源说明。
- 服务者端进入「我的个人信息与服务资料」，检查智能建档与认证/服务结果提示。
- 学生或服务者到「数据管理」，查看本地信息及预留接口；测试前切勿输入真实敏感资料。
- 游客仍受原来的身份和页面限制，没有真实账号权限。

## 技术状态与边界

- 当前为可点击 H5 **本地演示**；AI 内容提取和任务建议是有限规则，经验库是虚构示例；没有真实 AI、支付、云数据库、有效用户登录、跨设备同步和资质审核。
- 文字输入与 TXT/MD 文本可在浏览器内整理；PDF/Word 暂不解析正文；语音取决于浏览器支持情况，可能涉及其语音服务。
- 已测试主要交互与 320、375、390、430px 的浏览器布局；仍建议在 iOS 和 Android 真机实测软键盘、语音和长内容滚动。
